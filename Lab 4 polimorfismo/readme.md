# ArenaGT - Laboratorio 4: Polimorfismo

Programa de consola en Java para administrar torneos deportivos entre empresas. Utiliza clases abstractas, interfaces, herencia y polimorfismo para manejar las reglas de cada disciplina.


## el programa se inicia desde `Principal.java`, porque esa clase contiene el método `main`. Si se utiliza un entorno de desarrollo, se debe ejecutar la clase `Principal`.

## Funciones principales

Registrar participantes y crear torneos.
 Cotizar e inscribir participantes.
 Cerrar inscripciones y generar eventos.
 Programar y reprogramar eventos, verificando conflictos.
 Registrar resultados según las reglas de cada disciplina.
 Consultar tablas de posiciones, campeones y calendarios.
 Consultar ingresos, premios y ranking de empresas.

Las disciplinas disponibles son fútbol sala, fútbol sala con penales, baloncesto, voleibol y relevos.
